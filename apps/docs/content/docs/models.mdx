# AI Models & Orchestration

Access top-tier LLM providers (Anthropic, OpenAI, Google, DeepSeek) through a single unified API endpoint with automatic failover and cost optimization.

## Supported Providers

- **OpenAI:** GPT-4o, GPT-4o-mini
- **Anthropic:** Claude 3.5 Sonnet, Claude 3 Opus
- **Google:** Gemini 1.5 Pro, Gemini 1.5 Flash
- **DeepSeek:** DeepSeek V3, DeepSeek R1
