# Command Line Interface (CLI)

Manage your Falbor workflows, web applications, and deployments directly from your terminal.

## Installation

```bash
npm install -g @falbor/cli
```

## Quick Start

Authenticate with your Falbor workspace:

```bash
falbor login
```

## Core Commands

### `falbor dev`
Start local development environment and live preview bridge.

### `falbor deploy`
Deploy current workspace project to production edge instances.

### `falbor status`
Check active background workers, agents, and active workspace services.
