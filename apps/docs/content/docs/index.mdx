# Falbor Platform Documentation

Welcome to the Falbor documentation. Learn how to use our agentic AI platform to build websites, manage databases, orchestrate workflows, and deploy applications to production.

---

## Website Builder

Transform your ideas into fully functional, responsive websites instantly. Our agentic AI writes production-ready code so you can focus on growing your business.

### Why use the AI Website Builder?
- **Instant Generation:** Describe your vision, and our AI will scaffold a complete project in seconds.
- **Production-Ready Code:** Generates clean, maintainable React code using modern frameworks and best practices.
- **Real-time Preview:** See your changes rendered instantly as the AI continues to build and iterate.
- **Responsive by Default:** Every site is built to look great on desktop, tablet, and mobile devices automatically.

---

## Integrated Database

Every site gets a powerful database out-of-the-box. No need to configure external storage—every chat and site automatically provisions a secure, scalable database instantly.

### Key Database Features
- **Zero Configuration:** No connection strings, no provisioning, no hassle.
- **Relational & Document Stores:** Support for structured SQL tables as well as flexible JSON data storage.
- **Edge Optimized:** Data is geographically distributed and cached at the edge for fast global read speeds.
- **Automatic Backups:** Point-in-time recovery and automated daily snapshots.

---

## Organizations & Team Workspaces

Collaborate seamlessly with team members across shared workspaces, roles, and granular permission controls.

### Features
- **Role-Based Access Control (RBAC):** Assign Admin, Developer, or Viewer permissions to workspace members.
- **Shared Resources:** Share databases, workflows, and secret credentials across team members safely.
- **Audit Logging:** Track all changes, deployments, and database updates made by your team.

---

## Agentic Workflows

Design, simulate, and deploy complex AI agent workflows using our visual drag-and-drop workflow canvas.

### Core Capabilities
- **Visual Nodes:** Connect LLMs, database queries, webhooks, and code blocks visually.
- **Subflow Composition:** Reusable subflows for modular agent logic.
- **Real-time Execution Tracing:** Debug step-by-step execution outputs live in the browser.

## Command Line Interface (CLI)

Manage your Falbor workflows, web applications, and deployments directly from your terminal.

### Installation & Commands
```bash
npm install -g @falbor/cli
falbor login
falbor dev
falbor deploy
```
