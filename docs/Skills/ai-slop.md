# AI-Slop Detector

**Description:**
This skill instructs the AI to evaluate a product's interface to identify obvious "AI-slop" elements—visual cues that make the design look cheaply or hastily generated by AI rather than thoughtfully designed by humans. The AI must launch a browser to evaluate the site.

**Execution Context:**
- The AI must launch the browser using its available browser tools.
- It will navigate to the target site and analyze the visual design.

**Evaluation Criteria:**
- **Generic Shadows & Gradients:** Overuse of basic drop-shadows or default CSS gradients without nuance or purpose.
- **Inconsistent Layouts:** Misaligned items, lack of a coherent grid, or haphazard spacing (margin/padding) typical of unchecked AI code generation.
- **Default Typography:** Relying entirely on generic browser fonts or unstyled system fonts for branding.
- **"Placeholder" Aesthetics:** Using generic stock photos, unstyled placeholder text, or repetitive icons that lack brand context.
- **Overly Verbose Copy:** Walls of text without proper hierarchy or breaking (a common artifact of AI-generated content).

**Output:**
Return a list of specific "AI-slop" elements found, including exactly where they are on the page, and suggest specific CSS/design improvements to fix them.
